## ModelList

### Aquila-Med

Aquila-Med is a bilingual medical language model trained through continued pre-training, supervised fine-tuning, and preference alignment.

- Paper: [Aqulia-Med LLM: Pioneering Full-Process Open-Source Medical Language Models](https://arxiv.org/abs/2406.12182)
- Technical report: [Aquila_med_tech-report.pdf](./Aquila_med_tech-report.pdf)
- Model: [BAAI/AquilaMed-RL](https://huggingface.co/BAAI/AquilaMed-RL)
- SFT data: [BAAI/AquilaMed-Instruct](https://huggingface.co/datasets/BAAI/AquilaMed-Instruct)
- Preference data: [BAAI/AquilaMed-RL](https://huggingface.co/datasets/BAAI/AquilaMed-RL)
